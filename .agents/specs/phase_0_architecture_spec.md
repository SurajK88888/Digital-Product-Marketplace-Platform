# PHASE 0 – Software Architecture

## Objective

Design the complete software architecture for a production-grade, enterprise-level digital marketplace platform before writing any code. This phase establishes the technical foundation for the entire application and serves as the blueprint for all future development phases.

## The prompt should generate:

### 1. Folder Structure

* Frontend folder architecture
* Backend folder architecture
* Shared modules
* Configuration structure
* Assets organization
* Infrastructure directory
* Testing directory
* Documentation directory

### 2. System Design

* High-Level Architecture (HLD)
* Low-Level Architecture (LLD)
* Modular Architecture
* Clean Architecture
* Domain-Driven Design (DDD)
* Service boundaries
* Data flow diagrams
* Request lifecycle
* Component interaction diagrams

### 3. ER Diagram

* Complete Entity Relationship Diagram
* Entity relationships
* Cardinality
* Primary keys
* Foreign keys
* Junction tables

### 4. Database Design

* Database schema
* Tables
* Relationships
* Constraints
* Indexes
* Partitioning strategy
* Soft deletes
* Audit fields
* Versioning strategy

### 5. API Design

* REST API architecture
* Endpoint structure
* API versioning
* Authentication strategy
* Response standards
* Error handling format
* Pagination
* Filtering
* Sorting
* Search
* Rate limiting
* API documentation strategy

### 6. Authentication Flow

* User registration
* Login
* Logout
* Refresh tokens
* OAuth
* Email verification
* Password reset
* Two-Factor Authentication (2FA)
* Session management
* Multi-device login
* Role-Based Access Control (RBAC)

### 7. Payment Flow

* Shopping cart workflow
* Checkout process
* Payment gateway integration
* Webhooks
* Order confirmation
* Invoice generation
* Refund workflow
* Subscription handling
* Payment failure handling

### 8. Download Flow

* Secure file delivery
* Signed download URLs
* License verification
* Download permissions
* Download history
* Version downloads
* File storage architecture

### 9. Notification Flow

* Email notifications
* In-app notifications
* Push notifications
* SMS notifications
* Queue processing
* Retry mechanism
* Notification templates

### 10. Logging & Monitoring Flow

* Application logging
* API logging
* Error logging
* Audit logs
* User activity logs
* Security logs
* Monitoring architecture
* Alerting strategy
* Health checks

### 11. Deployment Flow

* Development environment
* Staging environment
* Production environment
* Docker architecture
* CI/CD pipeline
* Reverse proxy
* CDN integration
* Backup strategy
* Disaster recovery plan
* Horizontal scaling strategy
* Zero-downtime deployment
